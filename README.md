# AI Tender Summarizer (Умный суммаризатор тендеров)

Асинхронный микросервис на FastAPI, который принимает на вход PDF-файлы тендерной документации (техзадания, проекты контрактов с сайтов госзакупок) и с помощью больших языковых моделей (LLM) генерирует строго валидированную структурированную выжимку: сумму контракта, сроки, требования к исполнителю и штрафные санкции.

## 🚀 Ключевые особенности и архитектурные решения

- **Structured Outputs (Гарантия структуры):** Вместо классического текстового парсинга ответов нейросети, сервис использует режим `response_format={"type": "json_object"}`. Это гарантирует, что LLM всегда возвращает валидный JSON, строго соответствующий схеме.
- **Двойная валидация (Pydantic v2):** Данные валидируются как на уровне эндпоинта FastAPI, так и в момент получения сырого ответа от API нейросети.
- **Полная асинхронность:** Все сетевые операции (чтение файлов, запросы к API LLM) реализованы неблокирующим образом с помощью `async/await` и клиента `AsyncOpenAI`.
- **Гибкость провайдеров (OpenAI / Ollama):** Код спроектирован так, что переключение с коммерческого OpenAI API на локальные бесплатные модели (например, через Ollama) происходит изменением одной переменной окружения (`OPENAI_BASE_URL`), без модификации самого кода.
- **Эффективный парсинг PDF:** Использование библиотеки `PyMuPDF` (`fitz`) обеспечивает высокую скорость извлечения текста без необходимости разворачивания тяжеловесных Java-зависимостей.

## 🛠️ Технологический стек

- **Language:** Python 3.11+
- **Framework:** FastAPI / Uvicorn
- **Data Validation:** Pydantic v2
- **PDF Processing:** PyMuPDF (fitz)
- **AI Integration:** OpenAI API SDK (с поддержкой асинхронности)

## ⚙️ Инструкция по локальному запуску

### 1. Клонирование репозитория и подготовка окружения

```bash
git clone https://github.com
cd tender-summarizer

python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или venv\Scripts\activate  # Для Windows
```

### 2. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта на основе шаблона:

```bash
cp .env.example .env
```

Заполните его данными:

```env
# Для работы через OpenAI API:
OPENAI_API_KEY=your_real_openai_api_key_here
OPENAI_BASE_URL=https://openai.com

# ИЛИ для работы локально через Ollama (например, с моделью llama3):
# OPENAI_API_KEY=ollama
# OPENAI_BASE_URL=http://localhost:11434/v1
```

### 4. Запуск сервера

```bash
uvicorn app.main:app --reload
```

После запуска сервер будет доступен по адресу: `http://127.0.0.1:8000`

## 📊 Использование API (Интерактивная документация)

Интерактивная документация Swagger UI автоматически доступна по ссылке:
👉 **[http://127.0.0](http://127.0.0)**

### Основной эндпоинт:

- **Метод:** `POST`
- **Путь:** `/api/v1/summarize`
- **Тело запроса (Multipart/Form-Data):** `file` (загрузка файла с расширением `.pdf`)
